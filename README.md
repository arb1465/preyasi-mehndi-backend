# Preyasi Mehndi Art Gallery – Backend

This repository contains the **backend portion** of the Preyasi Mehndi Art Gallery full-stack application. Built with **Node.js** and **Express.js**, it serves RESTful APIs for the frontend to interact with. The backend handles booking requests, gallery image management, user-authentication (JWT), and integrates external services like Cloudinary and Brevo for image storage and email communication.

## 🛠 Features  
- Secure user & admin authentication using **JWT tokens**.  
- CRUD operations for gallery images (add, remove, categorize) and booking requests.  
- Review management (customer reviews: add, approve, delete) by admins.  
- Image uploading & management through **Cloudinary**.  
- Email notifications and communications handled via **Brevo API**.  
- Integrated AI-based pattern generation request handling (frontend triggers and backend serves).  
- MongoDB database for storage and Mongoose for schema modelling, including data validation and relationships.

## 🧪 Technologies Used  
- Runtime/Framework: Node.js, Express.js  
- Database: MongoDB (via Mongoose)
